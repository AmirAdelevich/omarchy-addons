# Omarchy Add-ons

## Плагин Omarchy

На Omarchy x86-64 установи виджет из терминала:

```bash
omarchy plugin add https://github.com/AmirAdelevich/omarchy-addons.git --enable
```

Нажми значок пакета в верхней панели. Первая цифра номера — блок, остальные — пункт внутри блока. Например, `111 21 33` поставит Chrome браузером по умолчанию, плагин Fans и усиление звука. Несколько номеров пишутся через пробел или запятую.

**1. Программы**

11. Google Chrome (AUR).
12. Visual Studio Code (AUR).
13. Telegram Desktop.
14. Tailscale и служба `tailscaled`.
15. LibreOffice Fresh, если не установлен Still.
16. Papers для PDF.
17. Веб-приложения Google Фото, Диск, Сообщения.
18. КриптоПро CSP, CAdES и JaCarta.
19. Hiddify.
110. Майнер Kryptex (SRBMiner).

**2. Плагины**

21. Fans — обороты вентиляторов MSI Katana (плагин и helper).
22. Pulse — процессор, память, GPU, температуры и потребление.

**3. Настройки**

31. Мышь: чувствительность `0` без ускорения.
32. NoGaps: убрать отступы окон.
33. Усиление звука динамиков: цифровое усиление с ограничителем (см. раздел ниже).
34. Прокрутка колёсиком в Chrome.
35. Google Chrome браузером по умолчанию.
36. TRIM: проверить состояние и переключить асинхронное отбрасывание блоков Btrfs.
37. Автозапуск Google Chrome в графической сессии и Hermes Agent через systemd пользователя.

**4. Оборудование**

41. Профиль вентиляторов MSI Katana с проверкой модели, ядра и прошивки.
42. Микроскоп H1600: просмотр, запись видео, фото и настройки качества.

**5. Рабочий стол**

51. Снимок рабочего стола с резервной копией. Текущие файлы `hypr/input.lua` и `hypr/looknfeel.lua` сохраняются, виджет добавляется в правую секцию панели.

Ту же нумерацию можно использовать из терминала:

```bash
bash addons-menu.sh --list          # показать меню
bash addons-menu.sh --run 17 33     # веб-приложения и усиление звука
bash install-runtime-settings.sh status
bash install-runtime-settings.sh trim on
bash install-runtime-settings.sh autostart on
```

Пункты блока 1, а также 34 и 35 устанавливают только выбранное: каждый из них — отдельный вызов `install-all.sh` с именем компонента, например `bash install-all.sh chrome`.

### TRIM и автозапуск

Пункт **36** показывает состояние TRIM: параметры Btrfs для `/`, системный таймер `fstrim.timer` и разрешение discard в параметрах LUKS. Режим `on` включает `discard=async` для Btrfs в `/etc/fstab`, применяет его сразу ко всем смонтированным Btrfs-разделам и отключает еженедельный таймер, чтобы не выполнять дублирующий TRIM. Режим `off` ставит `discard=none` и отключает таймер. Изменение `/etc/fstab`, перемонтирование и управление системным таймером требуют пароль `sudo`; перед правкой создаётся резервная копия `/etc/fstab`. Разрешение discard в настройке LUKS остаётся установленным, но при `discard=none` файловая система не отправляет discard-команды.

Пункт **37** включает или выключает службы Chrome и Hermes Agent. Chrome запускается после старта графической сессии из обычного профиля; watchdog поднимает браузер снова после его завершения. Расширения и профиль Chrome скрипт не меняет. Hermes Agent запускается как пользовательская служба на порту `9119`; для доступа по LAN настрой в Hermes парольную авторизацию. Если Hermes Agent не установлен, его служба пропускается. Конфиги перед заменой сохраняются в резервную копию.

Для установки пакетов и системных настроек может потребоваться пароль sudo.

Обновление плагина:

```bash
omarchy plugin update io.github.amiradelevich.omarchy-addons
```

## NoGaps

После установки Omarchy открой терминал и выполни:

```bash
git clone https://github.com/AmirAdelevich/omarchy-addons.git
cd omarchy-addons
bash install-no-gaps.sh
```

Скрипт задаёт нулевые отступы по краям и между окнами в `hypr/looknfeel.lua`, сохраняет текущую толщину рамок и перечитывает настройки Hyprland.

Если на рабочем столе включена прокрутка (Scrolling), выбери плиточную раскладку Tiling (Dwindle) в меню раскладок Omarchy. В режиме прокрутки колонки могут оставлять место у краёв даже при нулевых отступах. Из режима Scrolling можно сразу вернуться в Tiling командой `omarchy-hyprland-workspace-layout-toggle back`, запущенной на нужном рабочем столе.

## Микроскоп H1600

Дополнение для USB-микроскопа OSEECAM H1600 (`0ac8:3420`, 16 МП, UVC/MJPEG);
работает и с любой UVC-камерой, которая отдаёт MJPG. Установка — пункт **42**
меню или вручную:

```bash
bash microscope/install.sh
```

Что появляется в меню приложений:

- **«Микроскоп (H1600)»** — живой просмотр с кнопками **Запись** (H.264 в
  `~/Videos`), **Фото** (`~/Pictures`), **Настройки** и **Во весь экран**.
  Горячие клавиши: `r` — запись, `p` — фото, `F11` — полный экран.
- **«Микроскоп — настройки»** — разрешение и частота кадров, яркость, контраст,
  насыщенность, резкость, баланс белого и экспозиция. Применяется сразу, в том
  числе во время просмотра; там же кнопки «Сброс», «Снимок» и «Просмотр».

Установщик ставит недостающие пакеты (`ffmpeg`, `v4l-utils`, `python-gobject`,
`gtk4`, `libadwaita`), ярлыки, конфиг `~/.config/microscope/config` и правило
Hyprland, чтобы окно открывалось плавающим в формате 16:9 (бэкап
`hyprland.lua.bak.*`). Настройки просмотра — в том же конфиге:

```ini
VIEW_SIZE=1920x1080
VIEW_FPS=30
VIEW_CROP=0      # поставь 24, если у камеры зелёная полоса внизу кадра
```

Удаление: `bash microscope/uninstall.sh`. Подробности и диагностика —
в [`microscope/README.md`](microscope/README.md).

## Установка всего комплекта

Команды рассчитаны на Omarchy x86-64. Для скачивания публичного репозитория вход в GitHub не требуется.

### Новая машина

Если папки `~/omarchy-addons` ещё нет, выполни в терминале:

```bash
cd ~ && git clone https://github.com/AmirAdelevich/omarchy-addons.git && bash omarchy-addons/install-all.sh
```

### Машина, на которой комплект уже скачан

Если папка `~/omarchy-addons` уже есть, обнови копию и запусти установщик:

```bash
cd ~/omarchy-addons && git pull --ff-only && bash install-all.sh
```

Эта же команда подходит, если предыдущий запуск остановился на ошибке `$BROWSER is set and can't be changed with xdg-settings`. Обновлённый скрипт устанавливает комплект до настройки браузера. Если сменить браузер по умолчанию всё равно не удастся, он выведет предупреждение в конце.

Скрипт устанавливает Google Chrome и Visual Studio Code из AUR. Если Telegram Desktop ещё не установлен из репозитория Arch, скрипт устанавливает его из AUR. Tailscale устанавливается из репозитория Arch, а служба `tailscaled` включается автоматически. Для подключения к своей сети после установки выполни `sudo tailscale up`. В конце скрипт пытается назначить Google Chrome браузером по умолчанию для текущего пользователя.

Скрипт скачивает закреплённый архив из Releases, проверяет SHA-256 и устанавливает КриптоПро CSP с CAdES, JaCarta и Hiddify через pacman. Если Hiddify уже установлен, скрипт пропускает его установку. Скрипт включает PC/SC, добавляет системную политику расширения CAdES для Google Chrome, включает прокрутку нажатием колёсика для текущего пользователя и применяет NoGaps. Pacman может запросить подтверждение. После установки полностью закрой и снова открой Chrome.

Установщик добавляет в меню веб-приложения Google Фото, Google Диск и Google Сообщения. В Google нужно войти вручную, а для Сообщений потребуется привязать телефон. Для документов скрипт устанавливает LibreOffice (если ещё нет Fresh или Still) и Papers для просмотра PDF.

Архив релиза также содержит исходные пакеты для пересборки и файл `INSTALL.md` с диагностикой считывателя и проверкой лицензии КриптоПро.

## Восстановление рабочего стола

Снимок обновлён 14 ноября 2026 года с текущей установленной системы. В нём сохранены тема **Nord**, обои **0-black-moon**, шрифт **iA Writer Mono S**, нулевые отступы окон, GDK_SCALE=2, раскладки us/ru с Alt+Shift, верхняя панель, док и приложения по умолчанию.

Из сторонних плагинов устанавливаются **Fans** (`msi.katana-fans`) с его helper и **Pulse** (`io.github.sanchokusika.pulse`) из репозитория `AmirAdelevich/omarchy-pulse`. Остальные сторонние плагины устанавливаются вручную. Верхняя панель содержит встроенные виджеты Omarchy, Fans и Pulse. Версии сторонних плагинов и дополнительные темы Astral и Azure Glow закреплены в `desktop/sources.tsv`.

### Pulse

Pulse показывает процессор, память, GPU, температуры и энергопотребление. Ватты CPU читаются из счётчиков Intel RAPL и требуют узкого правила sudoers, иначе в панели останутся только ватты GPU из `nvidia-smi`:

```sudoers
<username> ALL=(root) NOPASSWD: /usr/bin/cat /sys/class/powercap/intel-rapl\:0/energy_uj, /usr/bin/cat /sys/class/powercap/intel-rapl\:0\:0/energy_uj
```

Правило устанавливается в `/etc/sudoers.d/pulse-rapl`. После восстановления рабочего стола проверь его командой `sudo -n cat /sys/class/powercap/intel-rapl:0/energy_uj`.

### Новая машина

В терминале обычного пользователя Omarchy выполни:

```bash
git clone https://github.com/AmirAdelevich/omarchy-addons.git
cd omarchy-addons
bash restore-desktop.sh --packages
```

### Уже скачанный комплект

```bash
cd ~/omarchy-addons
git pull --ff-only
bash restore-desktop.sh --packages
```

Параметр `--packages` устанавливает базовые компоненты рабочего стола — шрифт iA Writer и Chromium. CryptoPro и основной набор приложений устанавливаются прежним скриптом `install-all.sh` из раздела выше.

Для применения только рабочего стола и необходимых ему компонентов запусти `bash restore-desktop.sh`. Для проверки состава снимка без применения настроек используй `bash restore-desktop.sh --dry-run`.

Сохраняются настройки часового пояса Europe/Moscow, GTK, Hyprland, терминалов, шрифтов, курсора, Fcitx5, Neovim, tmux, btop, VS Code, MIME-ассоциаций, ярлыки и параметры погоды. Старые настройки целевой машины сохраняются в приватном каталоге `~/.local/state/omarchy-addons/desktop.*` с учётом XDG_STATE_HOME.

### Вентиляторы MSI Katana

Для **Katana 17 B12VFK с прошивкой 17L5EMS2.115 и ядром 7.2.15-1-omarchy** можно дополнительно восстановить сохранённые кривые, режим и Cooler Boost:

```bash
bash restore-desktop.sh --packages --fan-control
```

Этот параметр проверяет модель, ядро, контрольную сумму модуля и прошивку, восстанавливает драйвер и его загрузку при запуске, устанавливает проверяемое правило sudoers для текущего пользователя и применяет профиль из `desktop/hardware/katana-profile.json`. Без него helper устанавливается для отображения показателей, а аппаратный профиль не применяется.

Учётные данные GitHub и других сервисов, подписки и конфигурации VPN, браузерные профили, история диктовки, буфер обмена и уведомления исключены из публичного снимка. На другом компьютере потребуется войти в свои приложения. Для применения масштаба к уже запущенным программам может потребоваться повторный вход в сессию.

## Усиление звука

На ноутбуках динамики часто уже работают на максимуме: в PipeWire стоит 100%, в ALSA `Master` и `Speaker` — 0 дБ, а ползунок Omarchy не поднимается выше 100%. Программно громче сделать нечего, поэтому аддон добавляет цифровое усиление и ограничитель:

- виртуальный выход **Loudness Boost** с усилением **+10 дБ**;
- лимитер удерживает пики на **−1 dBFS**, чтобы громкие треки не хрипели;
- физический выход остаётся под ним и по-прежнему отвечает за громкость, поэтому клавиши и ползунок Omarchy работают как раньше.

Установка из меню — пункт 7, или вручную:

```bash
bash install-sound-boost.sh            # +10 дБ
bash install-sound-boost.sh --gain 14  # сильнее, 1..24 дБ
```

Усиление применяется к динамикам, которые были выходом при установке. На HDMI и наушники оно не влияет: при переключении выхода звук идёт напрямую. Нужен пакет `lsp-plugins-lv2` — скрипт поставит его сам через pacman.

Убрать усиление и вернуть обычный выход:

```bash
bash install-sound-boost.sh --remove
```

Файлы аддона: `~/.config/pipewire/loudness-boost.conf`, `~/.config/pipewire/loudness-boost.conf.d/90-boost.conf` и служба `~/.config/systemd/user/loudness-boost.service`.

## Копирование и вставка

В Foot, Ghostty, Kitty и Alacritty Ctrl+C копирует выделенный текст, Ctrl+V вставляет содержимое буфера обмена. Ctrl+Alt+C останавливает выполняемую команду. Ctrl+Shift+C и Ctrl+Shift+V также доступны для копирования и вставки.

## Майнер Kryptex

Установка SRBMiner-MULTI 3.8.3 для NVIDIA на Omarchy x86-64:

```bash
cd ~/omarchy-addons
bash install-miner.sh
```

Установщик добавляет приложение «Запустить майнер». При нажатии оно перезапускает майнер и показывает журнал. Профиль Pearl использует пул prl-ru.kryptex.network:8048, логин krxXV29VP7.worker, ядро 2550 МГц со смещением +200, память 5001 МГц и лимит 160 Вт. Нужен драйвер NVIDIA. Установщик добавляет wget, foot и Python и может запросить пароль sudo.

Логин Kryptex записан в файле miner/start-srb-160w.sh и будет доступен всем, кому доступен репозиторий.
