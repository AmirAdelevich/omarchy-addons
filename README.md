# Omarchy Add-ons

## NoGaps

После установки Omarchy открой терминал и выполни:

```bash
git clone https://github.com/AmirAdelevich/omarchy-addons.git
cd omarchy-addons
bash install-no-gaps.sh
```

Скрипт задаёт нулевые отступы по краям и между окнами в `hypr/looknfeel.lua`, сохраняет текущую толщину рамок и перечитывает настройки Hyprland.

Если на рабочем столе включена прокрутка (Scrolling), выбери плиточную раскладку Tiling (Dwindle) в меню раскладок Omarchy. В режиме прокрутки колонки могут оставлять место у краёв даже при нулевых отступах. Из режима Scrolling можно сразу вернуться в Tiling командой `omarchy-hyprland-workspace-layout-toggle back`, запущенной на нужном рабочем столе.

## Установка всего комплекта

Команды рассчитаны на Omarchy x86-64. Для скачивания публичного репозитория вход в GitHub не требуется.

### Новая машина

Если папки `~/omarchy-addons` ещё нет, выполни в терминале:

```bash
cd ~ && git clone https://github.com/AmirAdelevich/omarchy-addons.git && bash omarchy-addons/install-all.sh
```

### Машина, на которой комплект уже скачан

Если папка `~/omarchy-addons` уже есть, обнови копию и запусти установщик:

```bash
cd ~/omarchy-addons && git pull --ff-only && bash install-all.sh
```

Эта же команда подходит, если предыдущий запуск остановился на ошибке `$BROWSER is set and can't be changed with xdg-settings`. Обновлённый скрипт устанавливает комплект до настройки браузера. Если сменить браузер по умолчанию всё равно не удастся, он выведет предупреждение в конце.

Скрипт устанавливает Google Chrome и Visual Studio Code из AUR. Если Telegram Desktop ещё не установлен из репозитория Arch, скрипт устанавливает его из AUR. Tailscale устанавливается из репозитория Arch, а служба `tailscaled` включается автоматически. Для подключения к своей сети после установки выполни `sudo tailscale up`. В конце скрипт пытается назначить Google Chrome браузером по умолчанию для текущего пользователя.

Скрипт скачивает закреплённый архив из Releases, проверяет SHA-256 и устанавливает КриптоПро CSP с CAdES, JaCarta и Hiddify через pacman. Если Hiddify уже установлен, скрипт пропускает его установку. Скрипт включает PC/SC, добавляет системную политику расширения CAdES для Google Chrome, включает прокрутку нажатием колёсика для текущего пользователя и применяет NoGaps. Pacman может запросить подтверждение. После установки полностью закрой и снова открой Chrome.

Установщик добавляет в меню веб-приложения Google Фото, Google Диск и Google Сообщения. В Google нужно войти вручную, а для Сообщений потребуется привязать телефон. Для документов скрипт устанавливает LibreOffice (если ещё нет Fresh или Still) и Papers для просмотра PDF.

Архив релиза также содержит исходные пакеты для пересборки и файл `INSTALL.md` с диагностикой считывателя и проверкой лицензии КриптоПро.

## Восстановление рабочего стола

Снимок рабочего стола восстанавливается отдельной командой. После `gh auth login` запусти в терминале Hyprland:

```bash
gh repo clone AmirAdelevich/omarchy-addons && bash omarchy-addons/restore-desktop.sh
```

Если репозиторий уже клонирован, выполни из его каталога:

```bash
git pull && bash restore-desktop.sh
```

Команда восстанавливает конфигурацию Hyprland, верхнюю панель, док с закреплёнными приложениями, ярлыки, тему Retro 82 и обои In the Groove, русские настройки ввода и плагины Omarchy. Темы Astral и Azure Glow также появятся в списке.

Заменённые файлы сохраняются в `~/.local/state/omarchy-addons/desktop.*` или в соответствующем каталоге `$XDG_STATE_HOME`. На другой машине может потребоваться повторный вход в сессию для применения настроек масштаба к уже запущенным программам.

Для виджета вентиляторов используется актуальная версия из репозитория `omarchy-fan`. Управление зависит от модели ноутбука, прошивки и драйвера MSI. Плагин Superwhisper восстанавливается из пакета приложения. Учётные данные, подписки VPN, сессии браузера и история диктовки в снимок не входят.
