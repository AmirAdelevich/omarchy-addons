# Микроскоп H1600 для Omarchy

Дополнение для USB-микроскопа **OSEECAM H1600** (`0ac8:3420`, 16 МП, UVC/MJPEG),
но работает и с любой UVC-камерой, которая отдаёт MJPG.

Ставит:

- **«Микроскоп (H1600)»** — окно с живым просмотром и кнопками:
  - **Запись** — H.264 в `~/Videos/Микроскоп-дата.mkv` (1920×1080, без обрезки);
  - **Фото** — снимок в `~/Pictures/Микроскоп-дата.jpg`;
  - **Настройки** — отдельное окно качества;
  - **Во весь экран** — показ без интерфейса (`F11`).
- **«Микроскоп — настройки»** — разрешение и частота кадров (сохраняются в
  `~/.config/microscope/config`), ползунки яркости, контраста, насыщенности,
  резкости, баланса белого и экспозиции. Меняются на лету, даже во время
  просмотра; кнопки «Сброс», «Снимок», «Просмотр».
- **Правило Hyprland** — окно открывается плавающим (`1280×800`, по центру),
  чтобы картинка 16:9 не растягивалась и не упиралась в тайлинг.
- **Фолбэк** `microscope-plain` — простой просмотр на ffplay без кнопок
  (низкая задержка, если нужен только показ).

## Установка

```bash
cd ~/omarchy-addons && git pull --ff-only
bash microscope/install.sh
```

Скрипт сам поставит недостающие пакеты (`ffmpeg`, `v4l-utils`, `python-gobject`,
`gtk4`, `libadwaita`), положит программы в `~/.local/bin`, ярлыки — в меню
приложений, добавит правило Hyprland в `~/.config/hypr/hyprland.lua`
(с бэкапом) и перечитает конфиг.

После установки в меню приложений появятся **«Микроскоп (H1600)»** и
**«Микроскоп — настройки»** (Super → набери «микроскоп»).

## Использование

1. Подключи камеру напрямую в USB-порт (без хаба) — так меньше сбоев кадров.
2. Открой «Микроскоп (H1600)».
3. Подстрой картинку в «Микроскоп — настройки»: экспозицию, яркость, баланс белого.
4. Запись и фото — кнопками сверху; горячие клавиши `r` и `p`, полный экран `F11`.

Настройки просмотра лежат в `~/.config/microscope/config`:

```ini
VIEW_SIZE=1920x1080   # разрешение камеры
VIEW_FPS=30           # частота кадров
VIEW_CROP=0           # строк снизу отрезать (0 — кадр целиком)
```

## Если что-то не так

- **Камера не найдена.** Проверь `v4l2-ctl --list-devices`; устройство должно
  быть с MJPG. Переподключи камеру.
- **Зелёная полоса внизу кадра.** Некоторые экземпляры камеры отдают
  недописанные JPEG (низ кадра не закодирован). В `config` поставь
  `VIEW_CROP=24` — нижние 24 строки будут обрезаться.
- **Камера занята.** Одновременно камеру может держать только одно приложение:
  закрой просмотр/guvcview/VLC перед запуском записи из другого окна.
- **Тормозит превью.** Уменьши `VIEW_SIZE` (например, `1280x720`) или закрой
  окно настроек.

## Удаление

```bash
bash microscope/uninstall.sh
```

Удаляет программы, ярлыки, конфиг и правило плавающего окна (с бэкапом
`hyprland.lua.bak.*`).
